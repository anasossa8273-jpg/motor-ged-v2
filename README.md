# Motor GED de Interferencia L1 (Español -> Inglés) v2.0

API RESTful desarrollada con **FastAPI** y **spaCy** para la detección automatizada de errores gramaticales (GED) producidos por transferencia lingüística negativa del español (L1) al inglés (L2), ponderada por severidad y escalable por niveles del MCER (`A1-A2`, `B1-B2`, `C1`).

## Requisitos Previos
- Python 3.10 o superior
